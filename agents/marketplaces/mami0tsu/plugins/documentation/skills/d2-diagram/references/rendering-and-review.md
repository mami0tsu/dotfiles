# SVG 出力、watch、視覚確認

## 情報源

- 公式ドキュメント：[D2 Tour](https://d2lang.com/tour/intro/)、[CLI manual](https://d2lang.com/tour/man/)、[Layouts](https://d2lang.com/tour/layouts/)
- 検証バージョン：`d2 v0.7.1`
- 確認コマンド：`d2 --version`、`d2 --help`、`d2 layout`、`d2 layout dagre`

### SVG を出力する

#### 目的

検証済みの D2 ソースから、共有またはリポジトリへ保存できる SVG を生成する。

#### 前提条件

入力ファイルが存在し、`d2 validate <name>.d2` が成功していることを確認する。

既存の SVG を上書きしてよいか不明な場合は、別名の出力先を使うか利用者に確認する。

#### 推奨コマンド

```sh
d2 architecture.d2 architecture.svg
```

レイアウトを明示する必要がある場合だけ、利用可能なエンジンを `d2 layout` で確認してから指定する。

```sh
d2 --layout dagre architecture.d2 architecture.svg
```

#### 結果の確認

コマンドが成功し、指定した `.svg` が生成されていることを確認する。

続けて画像を表示し、視覚確認の項目を満たすことを確認する。

#### 停止条件

出力形式が SVG 以外である場合、出力先の上書き可否が不明な場合、またはレイアウトを変えることで図の意味が変わる場合は、利用者に確認する。

#### 代表的な失敗

- **症状**：`d2` が構文エラーを表示して SVG を出力しない。
  **原因の切り分け**：エラーに示された行のキー、コロン、中括弧、接続演算子を確認する。
  **次の確認**：修正後に `d2 validate architecture.d2` を実行してから再出力する。
- **症状**：図が読みづらい。
  **原因の切り分け**：ノード数、接続数、または全体の向きが一枚の目的に対して多すぎる可能性がある。
  **次の確認**：図を目的ごとに分けるか、`direction` を変更して再出力する。

### 編集中に watch する

#### 目的

編集中の `.d2` を保存するたびに再描画し、ローカルで SVG の変化を確認する。

#### 前提条件

入力ファイルと出力先を決める。

watch はローカル HTTP サーバーを起動するため、待機中のプロセスを終了できるターミナルで実行する。

#### 推奨コマンド

```sh
d2 --watch architecture.d2 architecture.svg
```

既定ではローカルの空きポートを使う。

ポートを固定する必要がある場合だけ、利用中でないポートを確認して指定する。

```sh
d2 --watch --host localhost --port 8080 architecture.d2 architecture.svg
```

#### 結果の確認

起動時に表示されたローカル URL を開く。

`.d2` を保存して、SVG またはブラウザー表示が更新されることを確認する。

#### 停止条件

`localhost` 以外へ公開する必要がある場合、固定ポートが他のプロセスで使われている場合、または作業環境でブラウザーを開けない場合は、自動で公開やポート変更をせず確認する。

#### 代表的な失敗

- **症状**：watch が起動しない、または URL を開けない。
  **原因の切り分け**：起動ログの host と port、固定ポートの競合、入力ファイルの構文エラーを確認する。
  **次の確認**：ポート指定を外して再実行するか、`d2 validate architecture.d2` を実行する。
- **症状**：保存後に図が変わらない。
  **原因の切り分け**：別のファイルを編集しているか、保存前の変更が残っている可能性がある。
  **次の確認**：watch の入力パスと編集対象を照合し、ファイルを保存してから起動ログを確認する。

### SVG を視覚確認する

#### 目的

構文検査では、SVG の見た目にある重なりと欠落を検出できない。
読みにくいラベルや誤った接続方向も同様である。

#### 前提条件

SVG が生成済みであり、SVG または SVG から変換したプレビュー画像を表示できることを確認する。

画像を表示できない環境では、視覚確認の完了を宣言せず、利用者に確認方法を相談する。

#### 推奨コマンド

SVG を画像表示ツールで開く。

SVG を直接扱えない表示ツールでは、環境に SVG 変換ツールがある場合だけ一時 PNG を作成する。

```sh
rsvg-convert architecture.svg -o architecture-preview.png
```

次を順に確認する。

1. ノード、container、接続、接続ラベルが欠けていない。
2. ラベルが他の要素や線と重なっていない。
3. 矢印の向きと分岐ラベルが意図どおりである。
4. 色や shape が意味の区別を助け、本文を読めないほど装飾されていない。

#### 結果の確認

表示した画像で四項目を確認し、問題があれば `.d2` を修正して SVG を再出力する。

最終成果物には `.d2` と `.svg` を残し、一時 PNG は成果物として必要な場合だけ残す。

#### 停止条件

重なりを直すために要素の意味、通信方向、または粒度を変える必要がある場合は、レイアウトだけで解決したと見なさず利用者に確認する。

#### 代表的な失敗

- **症状**：構文検査は成功するが、ラベルや線が重なる。
  **原因の切り分け**：1つの図に異なる目的の情報を入れすぎているか、接続ラベルが長すぎる可能性がある。
  **次の確認**：図を分ける、ラベルを短くする、または `direction` を変えて再出力する。
- **症状**：表示環境で SVG を確認できない。
  **原因の切り分け**：表示ツールが SVG を扱えない可能性がある。
  **次の確認**：利用可能な SVG 変換ツールの有無を確認し、一時 PNG を作って表示する。
