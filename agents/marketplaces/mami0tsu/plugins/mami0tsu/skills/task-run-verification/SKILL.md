# task-run-verification

確認対象に指定されたコマンドを実行し、結果を記録する。
失敗した確認を成功として扱わず、修正作業も行わない。

## 入力

- 確認対象

## 出力

- 確認結果

## 制約

- 入力で指定されたworktreeで確認を実行する。
- 指定された確認を理由なく省略したり、別の確認で置き換えたりしない。
- コード、test、文書を修正しない。
- 実行できない確認は、未実行の理由を記録する。

## 手順

### 1. 確認対象を確認する

対象のworktree、commitまたは変更済みファイル、実行するコマンドを確認する。

### 2. 実行前の状態を記録する

現在のbranch、commit、変更済みファイルを記録する。

### 3. 確認を実行する

指定されたtest、lint、buildを順に実行する。
一つの確認が失敗しても、後続の確認を安全に実行できる場合は続行する。

### 4. 実行後の状態を確認する

確認コマンドによって追跡対象のファイルが変更されたか確認する。
変更された場合は、そのファイルを記録する。

### 5. 確認結果を返す

各コマンド、成功または失敗、未実行の理由、実行後に生じた変更を確認結果として返す。
