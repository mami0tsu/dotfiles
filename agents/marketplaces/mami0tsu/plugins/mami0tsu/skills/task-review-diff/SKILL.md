# task-review-diff

対象commitの差分と周辺の実装を読み、修正が必要な問題を指摘する。
問題を見つけてもファイルやcommitは変更しない。

## 入力

- 仕様の読み取り結果
- commit済みの変更

## 出力

- 差分レビュー結果

## 制約

- 入力で指定されたbase commitと対象commitの差分だけをレビューする。
- コード、test、文書、commitを変更しない。
- 好みだけに基づく指摘を行わない。
- 問題がある箇所、影響、必要な修正、確認方法を具体的に示す。
- 問題がない場合は、修正が必要な指摘がないことを明示する。

## 手順

### 1. レビュー対象を確認する

現在のbranchと最新commitを確認する。
base commitと対象commitを確認する。
IssueまたはDocumentの内容を確認する。
対象を一つに決められない場合はレビューを開始せず停止する。

### 2. 差分と周辺の実装を読む

base commitと対象commitの差分を取得する。
変更された処理が使うコード、test、文書も確認する。

### 3. 要求とのずれを確認する

目的、変更範囲、受け入れ条件が差分に反映されているか確認する。

### 4. 既存機能への影響を確認する

変更によって既存の動作が壊れないか、必要なtestが不足していないか確認する。

### 5. 差分レビュー結果を返す

修正が必要な指摘を重要度順に並べ、問題箇所、影響、修正内容、確認方法を返す。
修正が必要な指摘がない場合は、その結果を返す。
