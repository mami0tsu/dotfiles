# task-clarify-requirements

調査で確定できない設計判断を1つずつ人間へ問い、決定と根拠を揃える。
1つの論点から新しい判断が得られなくなるまで確認してから、別の論点へ移る。

## 入力

- 設計準備結果
- 直前の設計成果物（再実行時）
- 修正指摘（再実行時）

## 出力

- 要求確認結果

## 制約

- 各質問の前に関係するリポジトリと入力を調べる。
- 調査で確定できる内容を人間へ質問しない。
- 1度に1つだけ質問し、推奨回答と根拠を添える。
- 曖昧な回答が設計判断を確定しない場合は、同じ論点を掘り下げる。
- 設計本文、Issue、Documentを変更しない。

## 手順

### 1. 未決事項を集める

要求の情報不足、矛盾、リポジトリ調査の未解決事項、修正指摘を列挙する。

### 2. 関係する事実を調べる

最初の未決事項に関係するコード、test、文書、設定を読み、選択肢を絞る。

### 3. 判断を確認する

選択肢、各選択肢の影響、推奨回答と根拠を提示し、一問だけ質問する。
回答が不足する場合は、同じ論点について次を質問する。

### 4. 論点を移す

現在の論点を決定事項または明示的な未決事項として記録した後、残りの論点へ進む。

### 5. 結果を返す

決定事項、根拠、確認済みの事実、未決事項を要求確認結果として返す。
