# task-apply-specification

実装準備結果で指定された範囲を変更する。
入力にない判断が必要になった場合は、推測で実装を続けず不明点を返す。

## 入力

- 実装準備結果
- 修正指摘（再実行時）

## 出力

- 変更結果

## 制約

- 入力で指定されたbranchとworktreeだけを使う。
- IssueまたはDocumentの範囲を超える変更を行わない。
- リポジトリ内の指示と既存の書き方に従う。
- commitを作らない。
- 作業開始前から存在する変更を上書きしない。

## 手順

### 1. 作業場所を確認する

現在のリポジトリ、branch、worktreeが実装準備結果と一致することを確認する。
一致しない場合はファイルを変更せず停止する。

### 2. 既存の実装を読む

変更候補とその周辺のコード、test、文書を読み、既存の書き方と依存関係を確認する。

### 3. 仕様を反映する

受け入れ条件を満たすために必要なファイルを変更する。
修正指摘がある場合は、指摘された問題を同じ変更範囲で修正する。
動作の追加や変更にtestまたは文書の更新が必要な場合は、同じ範囲で変更する。

### 4. 差分を確認する

変更済みファイルと差分に意図しない変更が含まれていないことを確認する。

### 5. 変更結果を返す

Issueの種類とID、作業用branch、worktree、変更済みファイル、実装内容、不明点を変更結果として返す。
