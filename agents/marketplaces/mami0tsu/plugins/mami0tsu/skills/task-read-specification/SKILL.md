# task-read-specification

入力されたIssueまたはDocumentを読み、記載されている内容を整理する。
読み取れない箇所や不足している情報は、推測で補わず明示する。

## 入力

- IssueまたはDocument

## 出力

- 仕様の読み取り結果

## 制約

- IssueまたはDocumentを変更しない。
- 入力に書かれていない内容を事実として追加しない。
- リポジトリを調査せず、実装方法も決定しない。

## 手順

### 1. 入力元を確認する

URL、識別子、ファイルパス、または入力された本文から、読む対象を特定する。
Issueを入力とする場合は、入力元が示すIssueの種類とIDを特定する。
Issue IDは入力元が返す表記を変えずに扱う。
対象を特定できない場合は、確認できなかった内容を返して停止する。

### 2. 内容を取得する

IssueまたはDocumentを、入力に対応する利用可能な方法で取得する。
本文から参照されているコメントや添付資料が実装条件に関係する場合は、その内容も取得する。

### 3. 実装条件を整理する

目的、変更範囲、受け入れ条件、確認方法に分けて記載内容を整理する。
該当する記載がない項目は、情報不足として残す。

### 4. 読み取り結果を返す

入力元、Issueの種類とID、整理した実装条件、情報不足、内容の矛盾を仕様の読み取り結果として返す。
Documentだけを入力とする場合は、Issueの種類とIDがないことを明示する。
