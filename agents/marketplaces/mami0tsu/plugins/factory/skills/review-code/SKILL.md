# Review Code

## 入力

| 項目 | 内容 |
| --- | --- |
| タスク | 作業範囲と受け入れ条件 |
| リポジトリ | worktree の絶対パス、比較元と実装のコミット |
| 検証結果 | 実行した確認とその結果 |

## 出力

| 成果物 | 内容 |
| --- | --- |
| レビュー結果 | 検証したコミットと修正が必要な指摘、または指摘なし |

## 手順

1. 指定されたコミット間の差分と関連コードを確認する。
1. タスクの受け入れ条件、動作への影響と検証結果を確認する。
1. 修正が必要な指摘は、該当箇所、発生条件と理由を loop に返す。
   指摘がなければ、その旨と検証したコミットを返す。
